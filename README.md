## Featured Projects

### Sign Language Detection System
**Real-time Computer Vision Application**

A webcam-based sign language recognition system using MediaPipe for hand landmark detection and a custom CNN trained with TensorFlow/Keras. Supports live prediction with confidence scores and includes tools for dataset collection and model training.

- **Tech:** Python · TensorFlow · Keras · MediaPipe · OpenCV · scikit-learn
- **Highlights:** Real-time inference · Custom dataset pipeline · Training visualization
- **Problem Solved:** Improves accessibility by translating hand signs into text predictions in real time

[View Repository](https://github.com/zillerehman-dev/SignLanguageDetectionSystem)

---

### AI Career Recommendation System
**Ensemble Deep Learning Application**

An intelligent career guidance tool powered by an ensemble of five Multi-Layer Perceptrons with soft voting. Users input education, skills, and interests to receive ranked career recommendations, confidence scores, roadmaps, and job search links through a Streamlit interface.

- **Tech:** Python · PyTorch · Streamlit · scikit-learn · SMOTE · Plotly
- **Highlights:** Ensemble modeling · Class balancing with SMOTE · Interactive UI · Career roadmaps
- **Problem Solved:** Helps users discover suitable career paths based on their profile with transparent confidence metrics

[View Repository](https://github.com/zillerehman-dev/Career_Recommendation_System)

---

### Fashion-MNIST CNN Classifier
**Image Classification Model**

A Convolutional Neural Network built from scratch for clothing image classification on the Fashion-MNIST dataset, achieving **91%+ test accuracy**.

- **Tech:** Python · TensorFlow · Keras · NumPy · Matplotlib
- **Highlights:** Custom CNN architecture · Strong generalization · Clear evaluation metrics
- **Problem Solved:** Demonstrates solid understanding of deep learning fundamentals applied to real image data
