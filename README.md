## 👋 About Me

I'm an **AI/ML Developer and Flutter Engineer** based in Pakistan, finishing my final year of a BS in Information Technology. My work sits at the intersection of two things: building **mobile applications that people can actually use**, and building **AI models that solve a real, specific problem** rather than just performing well on a benchmark.

On the mobile side, I build cross-platform apps in **Flutter**, usually with **Riverpod** for state management, **GoRouter** for navigation, and either **Firebase** or a custom **FastAPI + PostgreSQL/Supabase** backend, depending on what the project needs.

On the AI/ML side, I work across the pipeline from data collection and preprocessing, to training and evaluating models in **TensorFlow/Keras and scikit-learn**, to deploying them into a working interface with **Streamlit**, **Gradio**, or directly on-device via **TFLite**. My focus areas are **Computer Vision (gesture and keypoint recognition)**, **NLP/text classification**, and increasingly, **applied generative AI**.

The project I've spent the most time on is my Final Year Project a Pakistani Sign Language recognition app built with Flutter and TensorFlow Lite where I worked through the full pipeline: extracting hand/pose keypoints with MediaPipe, training a BiLSTM sequence model, converting it for on-device inference, and shipping it inside a real mobile app. That project taught me that the hardest part of ML is rarely the model it's making the model work reliably outside the notebook.

I'm currently completing a structured **AI/ML internship**, working through weekly production-style assignments (classification pipelines, NLP projects, model deployment), and I'm actively building toward taking on freelance and contract AI/ML and Flutter work.

## 🚀 Featured Projects

### 🤟 [Pakistani Sign Language Recognition — "Talk with Deaf"](https://github.com/zillerehman-dev/SignLanguageDetectionSystem)
*Final Year Project — Flutter + TensorFlow Lite*

A mobile app that translates Pakistani Sign Language into text/speech in real time.

- **Pipeline:** MediaPipe hand/pose keypoint extraction → BiLSTM sequence model trained in TensorFlow → converted to TFLite for fully on-device inference
- **App:** Flutter frontend (Riverpod + GoRouter, feature-based architecture) running the model live through the camera, with a companion Supabase backend
- **Problem solved:** on-device, offline-capable sign recognition for a low-resource language, aimed at improving everyday communication accessibility
- **Tech:** `Flutter` `TensorFlow` `TensorFlow Lite` `MediaPipe` `Python` `Supabase`

---

### 🩺 [Medical Report Specialty Classifier](https://github.com/zillerehman-dev/ai-ml-internship-advance-tasks)
*AI/ML Internship — NLP / Text Classification*

A text classification system that reads a medical transcription and predicts the medical specialty it belongs to.

- Trained and evaluated on the real-world `mtsamples` medical transcription dataset (~5,000 records)
- Reached **~91% accuracy** using a tuned Linear SVM with TF-IDF features, after a staged data-cleaning process that took the baseline from ~35% to ~91%
- Shipped as a working **Streamlit app** for live specialty prediction, alongside a full report and reproducible notebook
- **Tech:** `Python` `scikit-learn` `TF-IDF` `Streamlit` `Pandas`

---

### 📩 SMS Spam Classifier
*AI/ML Internship — NLP Pipeline*

An end-to-end spam-detection pipeline built on the SMS Spam Collection dataset.

- Combined **TF-IDF** feature engineering with **SMOTE** class balancing and an **ensemble model** to handle real-world class imbalance in spam data
- Packaged as a complete, submission-ready ML project with clear preprocessing → training → evaluation stages
- **Tech:** `Python` `scikit-learn` `SMOTE` `NLP`

### 🎯 [Career Recommendation System](https://github.com/zillerehman-dev/Career_Recommendation_System)
*Deep Learning — MLP*

A deep learning application that recommends a suitable career path based on user-provided details.

- Built on a Multi-Layer Perceptron (MLP) model trained to map personal/academic attributes to career predictions
- Designed as an end-to-end app: user input → preprocessing → model inference → recommendation
- **Tech:** `Python` `TensorFlow/Keras` `MLP`

### 🧵 Fashion-MNIST CNN Classifier
*Computer Vision — Image Classification*

A Convolutional Neural Network built from scratch for clothing image classification.

- 3-block CNN architecture with dropout and early stopping, evaluated with a full confusion matrix and classification report
- Reached **91%+ test accuracy**
